# Audit evidence

The checks behind the honesty claims in the README and the report. Everything here is a saved log, script or table. Nothing in the notebook or the report depends on it.

| Folder | What it is |
|---|---|
| `mutation_testing/` | 30 deliberately injected bugs in the Task 04 code. **`SUMMARY.md` gives the outcome per mutant: 30 of 30 caught.** It is generated by `summarize.py` from `logs/round_*`. Also here: `harness/` (`make_mut.py` holds the 30 patches; `runner.py`, `run_batch.sh`), `cfg/` (mutant and edge-case configs) and `edge_case_outputs/` (printed output of the 16 edge-case runs: checkpoint invalidation, failure injection, budgets, empty case lists). |
| `code_under_review/` | The exact Task 04 code that the bug and fairness/physics reviews used. The mutation patches target this version, which is earlier than the committed notebook cell. |
| `fairness_review/` | Fairness review: normalisation, duplicate or nested instances, calibration-vs-scored overlap, shared random streams, failure injection, checkpoint reuse and invalidation (scenarios `s_a`–`s_g`). Scripts and logs. |
| `physics_review/` | Physics review: simulator vs Qiskit circuit, sign conventions, LR / SPSA / CVaR checks, ablation (fields only vs couplings only), sign mutants (flipping the cost or mixer sign pushes ⟨E⟩ above uniform). Scripts and the logs that were saved. |
| `validation/` | Full-run logs with real compute times (`runs/`), the reduced large-mode dry run on the Mac before the HPC run, and the frozen-data test script. |
| `reproduction_20261010/` | Independent reproduction by a read-only audit agent: clean notebook run, the report numbers rebuilt from repo files, LaTeX build log. |

Literature checks (structured reports with DOIs, sign conventions and verbatim quotes, plus the numerical convention checks) are in `../../docs/literature/`.

Not saved: third-party paper copies (copyright), regenerated plots from the mutant work folders (about 400 MB, all reproducible), and a browser cookie file (deleted).
